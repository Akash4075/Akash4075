IoT-based monitoring and automation for silkworm farming, focused on environmental conditions and farm operations.

**Tech:** ESP32 · Arduino · IoT · Sensors · ThingSpeak

Real-time hand-gesture recognition system that converts recognized gestures into readable text.

- Uses computer vision for hand and gesture detection.
- Combines MediaPipe and TensorFlow-based techniques.

**Tech:** Python · OpenCV · MediaPipe · TensorFlow

</td>

### 🥛 SmartChill Milk Chilling Can

Portable milk chilling concept designed for small-scale dairy farmers.

**Tech:** IoT · Sensors · Thermal Management
